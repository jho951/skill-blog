우리의 소중한 기록

작은 응원이 모여 큰 힘이 됩니다. 오늘 하루도 고생한 당신에게 따뜻한 진심을 전해주세요. 이곳은 여러분의 다정한 이야기로 채워지는 공간입니다.

"당신은 생각보다 훨씬 더 멋진 사람이에요."

해학 블로그

'해학' 블로그 잘 보고 갑니다! 우연히 들렀는데 글이 너무 깔끔하네요. 앞으로도 좋은 백엔드 포스팅 기대할게요! 화이팅!

JPA 해결

JPA 벌크 연산 캐시 문제로 고생하다가 덕분에 5분 만에 해결하고 갑니다ㅠㅠ 트러블슈팅 기록 진짜 최고예요!

문제 해결 루틴

비전공자이신데도 가설 세워서 문제 해결하시는 과학적 루틴이 정말 멋집니다. 저도 많이 자극받고 갑니다. 응원할게요!

백준 DP

백준 DP 문제 해설 찾다가 왔어요. 코드가 너무 깔끔해서 이해가 쏙쏙 되네요! 코테 준비에 큰 도움 받았습니다.

인프라 모듈

직접 만드신 인프라 모듈들 깃허브에서 보고 구경 왔어요! 인증 모듈 아키텍처 고민하신 흔적이 돋보입니다. 최고!

다자바 히트맵

다자바 프로젝트 히트맵 시각화 글 흥미롭게 읽었습니다! UX 병목 현상 분석 아이디어가 정말 좋네요. 자주 올게요!

CRDT 동기화

블록 기반 에디터 CRDT 동기화 글 잘 봤습니다. 관련 한글 자료가 적어서 막막했는데 사막의 오아시스 같네요!

MSA & DDD

MSA랑 도메인 주도 설계(DDD) 아키텍처 글 너무 유익해요. 실무에 바로 적용해보고 싶을 정도로 정리가 잘 됐네요!

Security 흐름

Spring Security 필터 흐름 정리 글 보고 인증 구조가 훨씬 선명해졌어요. 실습하면서 다시 참고하겠습니다!

운영 로그

장애 로그를 따라가며 원인 좁혀가는 과정이 인상적이었어요. 실무 트러블슈팅 감각 배우고 갑니다.

테스트 코드

테스트 코드 작성 기준을 설명해주셔서 리팩터링할 때 큰 도움이 됐습니다. 예제도 깔끔해서 좋았어요.

성능 개선

쿼리 성능 개선 글 덕분에 실행 계획을 보는 관점이 생겼어요. 다음 글도 기대하겠습니다!

꾸준한 기록

꾸준히 기록하시는 모습이 멋집니다. 개발하면서 막힐 때마다 다시 찾아오게 되는 블로그예요.
